# Atividade sobre Estruturas de Dados

Nesta atividade, foi feito um projeto dividido em três partes, a primeira parte trabalha com listas para fazer uma lista sobre frutas onde o usuário pode até mesmo interagir e adionar uma nova fruta para a lista. Na segunda parte, foi criada uma tupla para simular uma coordenada fictícia e imutável. E na terceira parte, foi criado um produto fictício da marca Logitech usando a estrutura de dados dicionário.

## Tecnologias utilizadas

Python 3.14.0

## Como executar

Primeiro, verifique se o Python está instalado no seu computador na versão mais recente.

Caso ele já esteja instalado, clone este repositório usando o seguinte comando: 

```bash
git clone "https://github.com/joao-jvl-202509/atividade-colecoes-python.git"
```

Em seguida, rode o arquivo dentro de alguma IDE, como o VS Code, por exemplo.
